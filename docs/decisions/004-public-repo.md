# 004 — Public GitHub repository

**Status:** accepted · 2026-09-21

The repository is public. On GitHub Free, only public repositories get enforceable rulesets (required status checks) and unlimited Actions minutes. The code also works as a portfolio piece. No secrets ever live in the repo: they are Worker secrets, GitHub environment secrets, or git-ignored `.dev.vars`. The trade-off is that the site's implementation is visible to anyone, which is acceptable for a personal site.
